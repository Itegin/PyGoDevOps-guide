description: Деплой PyGoDevOps-guide на домашний сервер и проверка здоровья
---
Задеплой текущее состояние репозитория на сервер:

1. SSH на root@192.168.0.28
2. cd ~/PyGoDevOps-guide
3. Выполни: git pull
4. Выполни: docker compose up -d --build
5. Проверь: curl http://127.0.0.1:8080/healthz — должно вернуть {"status": "ok"}

Покажи вывод каждого шага. Если git pull не нашёл новых коммитов — остановись
и скажи мне, не пересобирай контейнер зря.
